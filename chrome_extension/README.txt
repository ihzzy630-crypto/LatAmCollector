LatAmCollector Chrome Helper v0.5.4

Install:
1. Open Chrome and visit chrome://extensions
2. Enable Developer mode in the top-right corner.
3. Click Load unpacked.
4. Select this chrome_extension folder.
5. Keep LatAmCollector running, open Shopee or SHEIN Brazil, and refresh the page.
6. On a category/search page, open the extension and click the bulk capture button.

Update an existing installation:
1. Replace the files in the currently loaded chrome_extension folder with the new ones.
2. Open chrome://extensions, click Reload on LatAmCollector Brazil Helper, and reopen the Shopee tab.
3. The popup has a button to open the Shopee Brazil homepage. Open a category or search result before starting collection.

The popup shows local service and Shopee page status independently. Shopee collection pauses on a page error or a verification prompt. Open a working product list manually before restarting collection.

Privacy:
- Captures only supported public Shopee/SHEIN product and review responses, plus public SHEIN product cards already rendered on the page.
- Sends them only to http://127.0.0.1:8765 on this computer.
- Does not read or transmit cookies, passwords, request headers, or Google account data.
- Bulk capture is user-initiated and rate-limited. SHEIN uses conservative scrolling/pagination, only follows real pagination controls, and safely pauses on verification, empty-result, blocked, or stalled pages.
